# Theme Switcher App

A simple and responsive React application that allows users to switch between Light and Dark themes. This project demonstrates the use of React Hooks and Context API for global state management along with Tailwind CSS for styling.

---

## Features

- Light and Dark mode toggle
- Global state management using Context API
- React Hooks (useState, useContext)
- Responsive UI with Tailwind CSS
- Smooth theme switching

---

## Tech Stack

- React JS
- Tailwind CSS
- Context API
- React Hooks
